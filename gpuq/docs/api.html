GpuQ: HTTP API

Служба слушает http://127.0.0.1:8189 (порт задаётся в config.json). Ответы — JSON в UTF-8. Запросы с именем хоста, отличным от 127.0.0.1:<порт>, localhost:<порт> или [::1]:<порт>, и POST с чужим заголовком Origin получают 403, и соединение закрывается: страницы чужих сайтов управлять службой не могут.

Граница доверия. Служба не знает, какая программа или какой пользователь Windows обращается к ней с этого же компьютера: любой локальный процесс может читать данные и менять очередь. Для общих компьютеров она не рассчитана.

Аренда карты

POST /gpuq/lease

ПолеТипСмысл
ownerстрока до 200 знаковкак задача называется в панели
vram_mbчислонужная видеопамять, МиБ; не меньше 1024; по умолчанию default_vram_mb
ram_mbчислооперативная память ПК, МиБ; 0 или не указано — не проверять
exclusivetrueкарта целиком
cardстрокаUUID карты (GPU-…) или её имя из панели
pidчислопроцесс клиента: пока он жив, аренда не снимается
sinceчислоUnix-время, с которого клиент ждёт (для отчёта об ожидании)
ttlчислосрок продления, секунд, от 30 до 300 (по умолчанию 120)

Ответы:

  • {"waiting": true} — карты пока нет; повторите запрос через 2 секунды с теми же owner и pid. Причину ожидания по каждой карте видно в панели и в журнале службы.
  • {"token": "…", "card": "GPU-…", "name": "RTX 4090", "ttl": 120, "shared": true} — карта выдана. Передайте card программе в CUDA_VISIBLE_DEVICES (вместе с CUDA_DEVICE_ORDER=PCI_BUS_ID).
  • {"error": "…"} — запрос отклонён.

Продление: {"token": "…", "ttl": 120} → {"released": false, "token": "…", "card": "GPU-…"}, либо {"error": "аренда истекла"}. Возврат: {"token": "…", "release": true} → {"released": true, …}.

Если в запросе был pid, аренду служба держит, пока процесс (по PID и времени создания) жив, даже если продления не приходят. Без pid аренда снимается, когда проходит ttl без продления.

Места для тяжёлых задач (необязательно)

POST /gpuq/slot с {"kind": "unity" | "heavy", "owner": "…", "pid": 1234}.

  • unity — до 4 одновременно, нужно свободно 6 ГБ RAM и 8 ГБ выделенной памяти; идёт первым.
  • heavy — до 2 одновременно, нужно свободно 10 ГБ RAM; уступает ожидающим unity.

Ответ {"granted": true, "token": "…"} или {"waiting": true, "why": "…", "position": 1}. Спрашивайте не реже раза в 30 секунд, иначе очередь забудет вас. Возврат: {"token": "…", "release": true}. Место освобождается само, когда процесс pid завершится.

Данные для панели (только чтение)

ЗапросЧто отдаёт
GET /gpuq/dashboard?limit=Nworkers (карты: name, state, reason, temp, util, used_mb, total_mb, power, power_limit, task), jobs, foreign (вычисления на картах), notices, alerts, pc (процессор, RAM), slots, summary
GET /gpuq/history?hours=24[&card=имя]минутные точки по каждой карте: загрузка, память, температура, мощность, состояние; сводка занятости. До 168 часов
GET /gpuq/report?days=7занятость устройств, ожидание заданий и аренд, топ скриптов по GPU-часам, число запусков мимо аренд. От 1 до 30 дней
GET /gpuq/gallery?limit=N&offset=Mрезультаты очереди ComfyUI с миниатюрами

Типы событий в notices: done, error — задания ComfyUI; bypass, bypass_long — работа на карте без аренды (второй тип — дольше 10 минут); lease_stuck — аренда держит память, а карта простаивает; vram_overflow — переполнена видеопамять; free, free_error — освобождение памяти чужого ComfyUI (если включено).

Очередь ComfyUI (бета)

Если в config.json указаны comfy_root, comfy_python и comfy_output, тот же порт отвечает как ComfyUI: POST /prompt, GET /history/<id>, GET /queue, GET /view, POST /upload/image, POST /queue {"delete": [id]}. В POST /prompt можно добавить "priority": N (число меньше нуля — фоновое задание) и "avoid": ["имя карты"]. Без настройки POST /prompt отвечает 503 с пояснением.
