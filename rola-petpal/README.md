# ROLA PetPal — домашняя станция

Статическая страница на GitHub и локальный пульт диагностики на Windows.

На 2026-10-17 подключение к API самого робота **не установлено**: адрес со скриншота не отвечает, MAC робота в локальной сети не найден. Управление движением, камерой, базой и лакомствами заблокировано до подтверждения совместимого API и авторизации. Телеметрия не имитируется.

## Запуск на ПК

`python -m pip install bleak`

`python discover.py` — поиск TCP-сервисов в сети 192.168.1.x и объявлений Bluetooth. Результат хранится только на ПК в `%LOCALAPPDATA%\RolaDashboard\discovery.json`.

`python start.py` — скрытый запуск пульта http://127.0.0.1:8794/. Кнопка «Повторить поиск» обновляет диагностику. Фоновый сервер слушает только loopback, внешний доступ не разрешён.

`python -m unittest test_server -v` — проверки доступа без команд настоящему роботу.

Публичная страница содержит только интерфейс. Для диагностики нужно открыть локальный пульт или импортировать локальный JSON; импорт выполняется в браузере, файл никуда не загружается. Реальные SN, MAC, Wi-Fi, учётные данные и результаты сканирования не публикуются.

## Совместимость

Интеграции EBO Air 2 не подтверждают поддержку ROLA PetPal. Исследование API продолжать только после обнаружения устройства; открытый TCP-порт сам по себе не означает доступ к API. Bluetooth может использоваться только при первоначальной настройке и не обязан постоянно объявлять робот.
