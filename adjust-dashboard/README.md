# Дашборд Adjust

Публичная страница: https://mrak0be5.github.io/adjust-dashboard/

Страница работает самостоятельно на GitHub Pages. Никаких серверов и ключей в браузере не требуется. Реальные данные Adjust автоматически выгружаются с основного ПК; опубликованная версия доступна и при выключенном ПК. Время выгрузки показано рядом с отчётом. При ошибке обновления остаётся предыдущая полная версия.

Комиссия сторов по умолчанию **30%** (`GROSS_70`), рекламная выручка — **AppLovin MAX SDK** (`applovin_max_sdk`). Adjust уже применил комиссию к IAP; повторного вычета нет. Изменение комиссии в интерфейсе пересчитывает только IAP, рекламная выручка остаётся прежней.

Работают произвольный период в пределах выгрузки, мультивыбор приложений, ОС, стран и рекламных сетей, фильтры кампаний, групп и креативов, дополнительные текстовые и числовые условия, выбор столбцов и группировок, сортировка, поиск, CSV и тёмная тема. Конструктор показывает только реально выгруженные показатели. Удержание агрегируется через вернувшихся пользователей и размер когорты; проценты не суммируются. Уникальная аудитория DAU не складывается из детальных строк и в этой версии не показывается.

Параметры валюты (USD), часового пояса (UTC), атрибуции, источника рекламной выручки, зрелости когорт и расходов зафиксированы при выгрузке. Неподдерживаемые варианты не предлагаются. Это версия с автоматическими выгрузками, а не прямое обращение в Adjust при каждом изменении фильтра.

Ключ хранится только на основном ПК, зашифрован Windows DPAPI. Файлы JSON содержат публичные аналитические данные, а не ключ. Фоновые запросы не выводят окна. Сборщик проверяет денежные итоги против Adjust и не публикует обрезанные отчёты.

Числовые условия применяются к таблице. Итоговые карточки и график показывают выбранный сегмент до числового порога; интерфейс это отмечает. Данные текущего дня неполные.

Исходники сборщика находятся в `source/`. Для частного прямого API на Windows используется `server.py`; публичной странице он не нужен.
